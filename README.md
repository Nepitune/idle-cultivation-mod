# Idle Cultivation Mod

Quality-of-life & balance mod for Idle Cultivation: faster timers, smoother XP curves, Auto-Quest with auto-crafting, live level-up countdowns, resource source breakdown, larger disciple cap, sharper sect & research maps, faster startup, many bug fixes, and an in-game auto-updater.

## Install (once)
1. Download [`release/IdleCultivationMod_v0.11.zip`](release/IdleCultivationMod_v0.11.zip).
2. In Steam: right-click **Idle Cultivation → Manage → Browse local files**.
3. Extract the zip into that folder and double-click `install.bat`.
   - **Heads-up:** Windows will most likely show a security warning ("The publisher could not be verified" or "Windows protected your PC"). This is **not** a virus detection. Windows shows it for every downloaded script that has no paid digital signature, which hobby mods like this one don't have. Click **Run** (or **More info → Run anyway**).
   - `install.bat` is a plain text file, so you can open it with Notepad first to see exactly what it does: it only copies the mod files into the game folder and into `%APPDATA%\Godot\app_userdata\Idle Cultivation\mods` (and, if an old patch backup `IdleCultivation.pck.original` exists, puts that original game file back).
4. Start the game through Steam as usual.

## Updates
New versions are offered by a popup inside the game shortly after it has loaded. **Install** downloads the update, which becomes active on the next start. **Not now** asks again next time. Without internet the game simply starts normally.

## Uninstall
Run `uninstall.bat`. Save files are not touched.

Requires that you own the game. Works only with the current game version.
